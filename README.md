## 1. Deskripsi Project

Aplikasi Web Pemesanan Buku merupakan aplikasi berbasis web yang dirancang untuk memudahkan pengguna dalam melihat informasi buku, melakukan pemesanan, serta memantau status pesanan. Aplikasi ini juga menyediakan fitur autentikasi pengguna dan pengelolaan stok buku.

## 2. Tujuan Pembuatan

Tujuan dari pembuatan aplikasi ini adalah:
- Mempermudah proses pemesanan buku secara online.
- Menyediakan informasi stok buku secara terstruktur.
- Mempermudah pengelolaan data buku.
- Memungkinkan pengguna melakukan tracking pesanan.
- Menerapkan konsep pemrograman web dalam sebuah aplikasi.

## 3. Proses Pengerjaan

### Tahap 1 — Perancangan Tampilan
Tahap awal dilakukan dengan merancang tampilan antarmuka aplikasi, mulai dari halaman awal, halaman login, dashboard, hingga halaman pemesanan dan tracking pesanan.

### Tahap 2 — Pembuatan Sistem Autentikasi
Mengembangkan fitur autentikasi pengguna yang terdiri dari:
- Login akun
- Registrasi akun baru
- Lupa password
- Validasi login berhasil dan gagal

### Tahap 3 — Pembuatan Dashboard
Membuat dashboard sebagai halaman utama setelah pengguna berhasil login. Dashboard berfungsi sebagai pusat navigasi untuk mengakses fitur-fitur aplikasi.

### Tahap 4 — Pengelolaan Data Buku
Mengembangkan fitur informasi stok buku yang mencakup:
- Melihat daftar buku
- Menambahkan buku baru
- Menghapus data buku

### Tahap 5 — Pembuatan Sistem Pemesanan
Mengembangkan fitur formulir pesanan agar pengguna dapat memilih dan memesan buku yang tersedia.

### Tahap 6 — Pembuatan Tracking Pesanan
Membuat fitur tracking pesanan untuk membantu pengguna mengetahui status dan perkembangan pesanan yang telah dibuat.

### Tahap 7 — Pengujian Aplikasi
Melakukan pengujian terhadap fitur-fitur yang telah dikembangkan untuk memastikan setiap halaman dan fungsi berjalan sesuai dengan tujuan.
